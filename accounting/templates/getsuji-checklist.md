# 月次締めチェックリスト

目標：毎月 **翌月10営業日まで** に締める（目安。会社の都合で変更可）。
各項目を ✅ 完了／⚠️ 要対応／— 対象外 で記入する。

## 1. データの取り込み（担当：keiri-shiwake）

- [ ] 全銀行口座の明細が月末日まで freee に取り込まれている
- [ ] 全クレジットカードの明細が月末日まで取り込まれている
- [ ] freee の「未処理の明細」が0件（残っている場合は件数と理由）
- [ ] 現金払いの経費・立替経費が精算・登録されている

## 2. 残高の一致（担当：keiri-kessan）

- [ ] freee の預金残高＝通帳・ネットバンキングの月末残高（口座ごと）
- [ ] freee のカード未払金残高＝カード会社の利用明細
- [ ] 現金残高＝実際の手元現金（現金を使っていなければ対象外）
- [ ] 仮払金・仮受金・未確定勘定・諸口の残高が0、または内容が説明できる

## 3. 売上・売掛金（担当：keiri-seikyu）

- [ ] 当月に成果が発生した取次手数料が、すべて当月の売上に計上されている（入金は翌月以降でも）
- [ ] 当月分の請求書がすべて発行されている
- [ ] 当月の入金がすべて消し込まれている
- [ ] 期日を過ぎた未入金の一覧を作り、対応を決めた
- [ ] 解約・キャンセルによる手数料の戻しが計上されている

## 4. 費用・買掛金（担当：keiri-shiharai）

- [ ] 当月分の請求書（広告・外注・SaaS・家賃・通信費）がすべて届き、計上されている
- [ ] 届いていない請求書は、見積額で未払計上するか翌月計上かを決めた（金額が大きいものは未払計上）
- [ ] 年払いの費用（ドメイン・保険・年間ライセンス等）は前払費用に計上し、月割りで費用にしている（金額が小さく毎年同じなら一括費用も可。方針を統一）
- [ ] 源泉徴収した税額を把握し、納付期限（翌月10日、または納期の特例の期限）を支払予定表に入れた
- [ ] 受け取った電子の請求書・領収書が freee のファイルボックス等に電子のまま保存されている

## 5. 人件費（担当：keiri-shiharai）

- [ ] 給与・役員報酬が計上されている（給与計算の結果と一致）
- [ ] 預り金（源泉所得税・住民税・社会保険料）の残高が、翌月の納付予定額と一致する

## 6. レビュー（担当：keiri-kessan → keiri-zeimu-review）

- [ ] 試算表の異常値チェックをした（前月比の大きな変動、マイナス残高、毎月の費用の抜け・重複）
- [ ] 税務チェック（keiri-zeimu-review）で「修正が必要」が0件
- [ ] 「税理士に確認が必要」の論点を税理士に送った
- [ ] 月次レポートを作成した

## 7. 締め（ユーザー）

- [ ] 内容を確認した
- [ ] freee の「月次締め」（締め処理）を実行した
