# 税制メモ（経理チーム用）

**最終確認日：2026-09-30**。ここに書いたのは作業時の目安です。申告・納付に直結する判断や、最終確認日から1年を超えた項目は、下の一次情報で最新を確認してから使うこと。

## 消費税・インボイス

| 項目 | 内容 | 当社への影響 |
|---|---|---|
| 未登録事業者からの仕入の経過措置 | 仕入税額相当額の一定割合を控除できる。**〜2026-09-30：80%**／**2026-10-01〜2028-09-30：70%**／2028-10-01〜2030-09-30：50%／2030-10-01〜2031-09-30：30%／その後は控除なし（令和8年度税制改正） | 取引日（課税仕入れを行った日）で割合を切り替える。9月分と10月分をまたぐ請求は日付に注意 |
| 2割特例 | 法人は **2026-09-30 を含む課税期間まで** | それ以後の課税期間は原則課税か簡易課税。方式は `common.md` に記入 |
| 3割特例 | 令和8年度改正で創設。**個人事業者のみ**（2027年分・2028年分） | 法人である当社は対象外 |
| 少額特例（1万円未満の仕入はインボイス不要） | 基準期間の課税売上高1億円以下等の事業者。期限は 2029-09-30 まで | 対象になるかは基準期間の売上で判定→要確認 |
| 公共交通機関の特例 | 3万円未満の鉄道・バス等の運賃はインボイス不要 | 帳簿に「公共交通機関特例」等と記載 |

## 源泉徴収（外注先が個人の場合）

| 項目 | 内容 |
|---|---|
| 対象 | 原稿料・デザイン料・講演料・専門家（税理士・弁護士等）への報酬など、所得税法で定められた報酬。**単なる作業の委託や営業代行は対象外のことが多い**ので、業務内容で判定する |
| 税率 | 1回の支払金額が100万円以下：10.21%／100万円超の部分：20.42% |
| 納付期限 | 支払った月の翌月10日（納期の特例を受けていれば 1〜6月分は7月10日、7〜12月分は翌年1月20日） |
| 法定調書 | 報酬の支払調書・法定調書合計表は翌年1月31日まで |

## 電子帳簿保存法

- メール・Web で受け取った請求書・領収書（電子取引データ）は、**紙に印刷して保存するのではなく電子のまま保存する**（2024-01-01 から義務）。
- 検索できるように「日付・金額・取引先」で探せる状態にする。freee のファイルボックスに登録すれば対応できる。
