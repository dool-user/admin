# 光回線LP WordPress版（テーマ: hikari-navi）

`lp/` の静的LPを WordPress テーマにしたものです。管理画面で電話番号・特典額・料金・FAQ・お客様の声を更新でき、
申込はWordPressに保存されメール通知されます（プラグインなしで動作）。

```
wordpress/
├── themes/hikari-navi/   … テーマ本体（これをサーバーの wp-content/themes/ に置く）
├── setup.sh              … 初期セットアップ（テーマ有効化・プラグイン導入・必須ページ・メニュー作成）
└── docker-compose.yml    … ローカル確認用（WordPress + MariaDB + メール確認用Mailpit）
```

## 本番公開の手順（レンタルサーバー）

1. サーバーで WordPress をインストール（エックスサーバー / ConoHa WING などの「簡単インストール」で可）
2. SSL（https）を有効化
3. `themes/hikari-navi` を zip にして「外観 > テーマ > 新規追加 > テーマのアップロード」
   （または FTP で `wp-content/themes/` にアップロード）
4. SSH で WordPress のディレクトリに入り、`setup.sh` を実行
   ```bash
   URL=https://your-domain.jp ./setup.sh
   ```
   ※SSHが使えない場合は、下の「プラグイン」を手動で入れ、固定ページ（プライバシーポリシー等）を作成し、
   「設定 > 表示設定」でホームページに固定ページを指定してください。
5. 「外観 > カスタマイズ > LP設定」で以下を入力
   - 基本情報：サイト名、**電話番号**、受付時間、**運営会社・電気通信事業届出番号**
   - キャンペーン：最大キャッシュバック額、サービス別金額表、プレゼント家電
   - 料金：戸建て／マンションの月額
   - フォーム・計測：通知先メール、**GTM ID**
6. 「固定ページ」の【要編集】箇所（プライバシーポリシー・特商法表記・会社概要・キャンペーン規約）を記入
7. 「お客様の声」「よくある質問」を登録（未登録の間はサンプル／初期FAQを表示。サンプルの声は管理者にだけ注意表示が出ます）
8. **WP Mail SMTP** を設定し、テスト送信でメールが届くことを確認（自動返信が迷惑メール入りするのを防ぐ）
9. フォームから実際にテスト申込 → 「申込一覧」に入る・通知メールが届く・自動返信が届くことを確認

## 管理画面でできること

| メニュー | 内容 |
|---|---|
| 申込一覧 | 申込の一覧・詳細、**対応状況**（未対応→連絡済み→申込完了→開通済み→特典送付済み）、社内メモ、**CSVダウンロード** |
| よくある質問 | タイトル＝質問、本文＝回答。「順序」で並び替え |
| お客様の声 | タイトル＝属性（例：30代・戸建て・新規）、本文＝コメント |
| 外観 > カスタマイズ > LP設定 | 電話番号・金額・料金・表記・フォーム・GTM |
| 外観 > メニュー | フッターのリンク |

## 広告計測（GTM）

カスタマイザーに GTM ID を入れると全ページにタグが入ります。テーマは次のイベントを `dataLayer` に送ります。

| イベント名 | タイミング | GTMでの設定例 |
|---|---|---|
| `generate_lead` | Webフォーム送信完了 | Google広告コンバージョン / GA4 キーイベント |
| `tel_click` | 電話番号タップ | 電話コンバージョン（スマホ） |

GTMで「カスタムイベント」トリガーを上記イベント名で作成し、Google広告・GA4のタグに割り当ててください。

## スパム対策（内蔵フォーム）

- ハニーポット（bot だけが入力する隠し項目）
- 表示から3秒未満の送信を拒否
- 同一IPから10分に5件まで
- nonce を使っていないので、キャッシュプラグインでページをキャッシュしてもフォームは壊れません

## Contact Form 7 を使いたい場合

CF7 をインストールしてフォームを作成し、そのショートコードを「LP設定 > フォーム・計測タグ」に貼ると内蔵フォームと置き換わります
（送信完了時の `generate_lead` 計測もそのまま動きます）。申込の保存が必要なら **Flamingo** も入れてください。

## プラグイン

`setup.sh` が自動で入れるもの：

| プラグイン | 用途 |
|---|---|
| WP Mail SMTP | 通知・自動返信メールの確実な配信 |
| SEO SIMPLE PACK | タイトル・description・OGP（導入するとテーマ内蔵のmeta出力は自動で止まります） |
| SiteGuard WP Plugin | ログインURL変更・不正ログイン対策 |
| UpdraftPlus | 定期バックアップ |
| EWWW Image Optimizer | 画像圧縮・WebP化 |

任意（`setup.sh` 内のコメントを外す）：Contact Form 7、LiteSpeed Cache（LiteSpeedサーバーの場合）、Site Kit by Google。

## ローカルで試す（Docker）

```bash
cd wordpress
docker compose up -d
WP="docker compose run --rm cli wp" ADMIN_PASS=admin ./setup.sh --install
# → http://localhost:8080 （管理画面 /wp-admin  admin / admin）
```
送信メールは http://localhost:8025 （Mailpit）で確認できます。WP Mail SMTP の「その他のSMTP」で
ホスト `mailpit`、ポート `1025`、暗号化なし、認証なしを設定してください。
