# 引越しの無料相談フォーム

note の A11（引越し・新生活）のコラムから、本業のサービス（お部屋探し・電気ガス水道・ネット回線・ウォーターサーバー・関東の引越し業者）の相談を受けるフォームです。1ファイルの静的ページ（`index.html`）。

## 公開のしかた（Google Apps Script・サーバー不要。10/1〜）
1. Google ドライブで新しいスプレッドシートを作る（名前の例：まるっと窓口 相談）→ メニューの「拡張機能」→「Apps Script」
2. 最初からある `コード.gs` の中身を消して、`gas/consult-form-receiver.gs` を全部貼る。1行目近くの `NOTIFY_TO` を、相談の通知を受けるメールアドレスに変える
3. 左の「ファイル」の「＋」→「HTML」→ 名前を `moving-form` にして、`moving-form/index.html` を全部貼る（もとの中身は消す）
4. 上の「デプロイ」→「新しいデプロイ」→ 種類「ウェブアプリ」／次のユーザーとして実行「自分」／アクセスできるユーザー「全員」→「デプロイ」→ 権限を承認
5. 出てきた「ウェブアプリの URL」（`https://script.google.com/macros/s/…/exec`）をチャットに貼る → 記事に入れる（`note/launch/settings.json` の `moving_form_url`）
6. 自分のスマホでその URL を開き、テストで1件送る → スプレッドシートの「引越し相談」シートに1行入り、メールが届けば OK

- 会社の HP・プライバシーポリシーへのリンクは載せない（10/1 社長）。運営の表示は「まるっと窓口」
- 記事には `URL?src=記事ID` で入れる。どの記事から相談が来たかがシートの src 列に入る
- note の記事には、フォームそのものは埋め込めない見込み。URL だけの行を置くと、リンクのカードとして表示される（公開用の本文は自動でそうなる）

## 気をつけること
- 「仲介手数料無料」は条件とセットで出す（宅建業の免許・提携先の表示は社長が確認）
- 紹介料を受け取る場合は、その旨の表示を消さない（景品表示法のステマ規制）
