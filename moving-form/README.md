# 引越しの無料相談フォーム

note の A11（引越し・新生活）のコラムから、本業のサービス（お部屋探し・電気ガス水道・ネット回線・ウォーターサーバー・関東の引越し業者）の相談を受けるフォームです。1ファイルの静的ページ（`index.html`）。

## 公開までにやること
1. `index.html` の `CONFIG` の「★要変更」を書き換える（会社名・仲介手数料が無料になる条件・紹介料の書き方・返信の目安・プライバシーポリシーの URL）
2. `gas/consult-form-receiver.gs` をデプロイし、URL を `CONFIG.endpoint` に入れる（MEO のフォームと同じ URL でよい。シートは「引越し相談」に分かれる）
3. Cloudflare Pages で公開（公開フォルダ `moving-form/`。でんき開通サポートの LP と同じドメインの下にするかは社長が決める）
4. 公開した URL を、コラム（N010〜N015）の【社長確認：引越し相談フォームのURL】に入れる（`?src=記事ID` を付けたまま）

## 気をつけること
- 「仲介手数料無料」は条件とセットで出す（宅建業の免許・提携先の表示は社長が確認）
- 紹介料を受け取る場合は、その旨の表示を消さない（景品表示法のステマ規制）
