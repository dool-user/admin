# 光回線申込LP（ヒカリナビ／仮ブランド）

bb-navi.jp（光回線の販売代理店LP）の構成を参考にした、オリジナルデザインのLPです。
ロゴ・社名・電話番号・金額はすべて **仮の値** です。公開前に必ず差し替えてください。

## ファイル構成
```
lp/
├── index.html        … LP本体
└── assets/
    ├── style.css     … デザイン（色は :root の変数で一括変更可）
    └── main.js       … メニュー / 料金タブ / 固定CTA / 郵便番号→住所 / フォーム送信
```

## ページ構成
1. ヘッダー（ロゴ・ナビ・フリーダイヤル）
2. ファーストビュー（最大80,000円キャッシュバック・3つの訴求・Web/電話CTA）
3. 選ばれる3つの理由
4. キャンペーン（キャッシュバック or 家電プレゼント、サービス別金額表）
5. 中間CTA
6. 月額料金（戸建て／マンション タブ切替）
7. 開通までの流れ（4 STEP）
8. お客様の声
9. よくある質問（アコーディオン）
10. Web申込フォーム（バリデーション・郵便番号から住所自動入力）
11. フッター（運営会社・プライバシーポリシー・特商法表記・届出番号）
12. スマホ用 画面下固定CTA（電話／Web）

## 公開前に差し替える箇所
| 項目 | 場所 |
|---|---|
| サイト名・ロゴ | `index.html` の `.logo`、`<title>`、フッター |
| 電話番号 | `0120-000-000` / `tel:0120000000` を一括置換 |
| 特典金額・料金 | キャンペーン表・料金カード |
| お客様の声 | 実際の声に差し替え（架空の声は景品表示法上NG） |
| 会社情報・届出番号 | フッター `.footer__legal` |
| フォーム送信先 | `assets/main.js` の `FORM_ENDPOINT` |
| 計測タグ | `<head>` に GA4 / Google広告 / GTM を追加（送信完了時に `generate_lead` イベントを送出済み） |

## ローカル確認
`index.html` をブラウザで開くだけで動作します（フォームは送信先未設定時デモ動作）。
