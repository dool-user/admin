# TikTok広告用動画（でんき開通サポート）

## 納品ファイル

| ファイル | 冒頭3秒のフック | 用途 |
|---|---|---|
| `tiktok_hook-a_18s.mp4` | 引越し初日の夜… / 電気つかない！？ / ブレーカー上げても真っ暗… | 状況再現型（本命） |
| `tiktok_hook-b_18s.mp4` | POV：引越し初日の夜 / 電気がつかない / え、手続きしてなかった…？ | POV型 |
| `tiktok_hook-c_18s.mp4` | 引越し予定の人へ / これ忘れると電気つかない / 意外とみんなやりがち | 呼びかけ型 |

- 仕様：1080×1920（9:16）、30fps、18秒、H.264 / AAC（無音トラック）、各約3.3MB
- 3本は冒頭3秒だけが違い、4秒目以降は共通です。同じ広告グループに入れて配信し、完全視聴率・CTR・CPAを比べて勝ちパターンに予算を寄せてください。

## 構成（18秒）

| 秒 | 内容 | ねらい |
|---|---|---|
| 0〜3 | 暗い部屋で電球が消える＋フック文字（1コマ目から表示） | スクロールを止める |
| 3〜7 | スマホのメモ風「引越し前にやること」→「電気の使用開始の申し込み」に赤丸「忘れがち！」 | 自分ごと化（あるある） |
| 7〜10.5 | 電気・ガス・水道・ネットの連絡先がバラバラ →「正直、めんどくさい…」 | 面倒さへの共感 |
| 10.5〜15 | 「まとめて頼めるところ、あります」＋ロゴ・イラスト・特長（最短即日開通※／相談無料／土日祝も受付） | 解決策の提示 |
| 15〜18 | 「引越し予定の人は 今のうちにチェック！」＋対応エリア＋「詳しくは下のボタンから」 | 行動喚起 |

広告っぽさを抑えるため、TikTokの文字入れ機能に似た白い箱文字・縁取り文字、手持ち撮影のような揺れ、カット切り替えにしています。ロゴは後半に一度出すだけです。

文字は、TikTokの右側のアイコン列と下部のキャプション・ボタンに重ならない範囲に収めています。

## 入稿時の設定（推奨）

- **音源**：無音で書き出しているので、広告マネージャーの「商用音楽ライブラリ」から明るめの曲を付けてください。普通の投稿で流行っている曲でも、商用利用が許可されていないものは使えません。
- **広告テキスト（どれか1つ）**
  - 引越し初日に電気がつかない…を防ぐなら、今のうちに申し込みを。ガス・水道もまとめて頼めます
  - 引越しの電気の手続き、忘れてない？ 相談無料・土日祝も受付中
  - 電気・ガス・水道の連絡、まとめてお任せ。1都6県の新居に対応
- **表示名**：でんき開通サポート（「東京電力」など実在の会社名や「公式」を入れない）
- **CTAボタン**：「詳しくはこちら」または「今すぐ申し込む」
- **リンク先URL**：どの動画から来たか分かるよう、パラメータを付けます
  `https://（本番ドメイン）/tokyo/?utm_source=tiktok&utm_medium=paid_social&utm_campaign=denki&utm_content=hook-a`
  （`utm_content` は動画ごとに hook-a / hook-b / hook-c）
- **計測**：TikTokピクセルをGTMで設置し、`tel_click` と `generate_lead` をコンバージョンに設定してください。広告クリック時に付く `ttclid` と `utm_content` はフォームで自動取得し、申込データに記録されます。

## 表示ルール（必ず守ること）

- 「電力会社の公式サービスではありません」「運営：グラハムコミュニケーションズ株式会社」の表記（最終カット）は消さない
- 「即日開通」には条件の注記（10.5〜15秒）を必ず付ける
- 実在しないお客様の感想や体験談を「本物のレビュー」として作らない（ステマ規制・景品表示法）。レビュー型にしたい場合は、実際のお客様やクリエイターに依頼し、許諾を取ったうえで広告であることを明示する
- 東京電力などのロゴ・ブランドカラー・社名を使ったフックにしない

## 作り直し方

`src/` にHTMLアニメーションと書き出しスクリプトがあります。文言を変えるときは `src/video_*.html` を編集してから、次を実行します。

```
cd lp/ads/tiktok/src
npm install
./build.sh   # ffmpeg（libx264入り）が必要
```
