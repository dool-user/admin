# TikTok広告 台本

## 台本1：いまの動画に付けるナレーション（18秒）

すでにある動画（hook-a / b / c）に、そのまま声を重ねる用です。1秒あたり6〜7文字の早口気味で、友だちに話すような口調にします。

| 秒 | 画面 | ナレーション |
|---|---|---|
| 0〜3 | 電球が消える／フック文字 | A：「引越し初日の夜、電気つかないんだけど！？」<br>B：「引越し初日の夜。…え、電気つかない。」<br>C：「引越し予定の人、これ忘れると電気つかないよ。」 |
| 3〜7 | メモ風リスト→「電気の使用開始」に赤丸 | 「原因これ。電気の使用開始の申し込み、忘れがちなんだよね。」 |
| 7〜10.5 | 電気・ガス・水道・ネットのカード | 「しかもガスも水道もネットも、連絡先ぜんぶバラバラ。正直めんどい。」 |
| 10.5〜15 | ロゴ・特長 | 「でも、まとめて頼めるところあるの。相談無料で、土日もOK。」 |
| 15〜18 | 対応エリア・矢印 | 「引越し予定の人は、今のうちにチェックしといて！」 |

- 画面上の注記（即日開通の条件）は読み上げなくてかまいません。
- 「即日開通」を声で言う場合は、「最短で当日から使えることもある」のように言い切らない表現にします。

## 台本2：実写で撮る「中の人」動画（約25秒）

スタッフ（または依頼したクリエイター）がスマホで自撮りする、普通の投稿に見える形式です。架空のお客様の体験談にはせず、**手続きを代行している側の人が話す**形にしています。

- 撮影：スマホ縦・自撮り・室内（段ボールがある部屋だとなお良い）
- 服装：私服（スーツや制服は広告っぽくなるので避ける）
- 文字：話している内容をそのまま字幕で出す。要点だけ大きく

| 秒 | 映像 | セリフ | 画面の文字 |
|---|---|---|---|
| 0〜3 | 暗い部屋。スマホのライトで顔を照らして | 「引越し初日の夜に、これ。電気つかない。」 | 引越し初日、電気つかない |
| 3〜7 | 部屋の電気をパチッと点ける→明るくなる | 「毎日こういう相談を受けてる、電気の申し込みの取次をしてる者です。」 | 電気の申し込み取次の中の人です |
| 7〜12 | カメラに近づいて指を1本立てる | 「原因でいちばん多いのが、電気の使用開始の申し込み忘れ。ブレーカー上げても、申し込みしてないとつかないことがあるんです。」 | 原因No.1＝申し込み忘れ |
| 12〜17 | 指を折って数える | 「しかも電気、ガス、水道、ネット、連絡先ぜんぶ別。引越し前にこれ全部やるの、正直しんどいですよね。」 | 電気／ガス／水道／ネット 全部別… |
| 17〜22 | 笑顔で | 「うちに一本連絡もらえたら、まとめて手配します。相談は無料、土日もやってます。」 | まとめて手配／相談無料・土日OK |
| 22〜25 | 画面の下を指さす | 「引越し決まった人は、下から今のうちにどうぞ！」 | 詳しくは下のボタンから |

### 撮影・編集のポイント
- 最初の1秒で「電気つかない」まで言い切る。前置きやあいさつは入れない
- 1カット3〜5秒でテンポよくつなぐ。言い間違いはカットでOK（多少のラフさがあった方が自然）
- BGMは広告マネージャーの商用音楽ライブラリから小さめに

### 必ず守ること
- 「東京電力」「公式」など、電力会社の窓口だと思われる言い方をしない
- 「絶対その日に使える」「必ず即日」と言い切らない（「最短で当日」「物件による」まで）
- 架空のお客様になりきって「使ってよかった」と話さない（ステマ規制・景品表示法）
- 外部のクリエイターに依頼する場合は、広告であることを明示してもらう（TikTok広告として配信する場合は「広告」表示が付く）
