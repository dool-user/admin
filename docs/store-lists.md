# 店舗リスト抽出ツール

2つのツールがあります。

| ツール | 内容 | 実行方法 |
|---|---|---|
| `tools/gmaps_uber_finder/` | Google マップで「オンラインで注文」に **Uber Eats が無い店** を抽出 | 自分のPCで画面から実行 |
| `tools/tabelog_newopen/` | 食べログの **新規オープン店** を抽出 | 毎朝8時に自動実行（GitHub Actions） |

---

## 1. Google マップ：Uber Eats 未対応店の抽出

### 準備（初回のみ）

Python 3.10 以上が入ったPCで、次を実行します。

```bash
cd tools/gmaps_uber_finder
pip install -r requirements.txt
python3 -m playwright install chromium
```

### 画面から使う

```bash
python3 app.py
```

ブラウザで http://localhost:8765 が開きます。

| 項目 | 内容 |
|---|---|
| 都道府県 | 47都道府県から選択 |
| 市区町村 | 候補から選ぶか入力（空欄なら都道府県全体） |
| 業種 | 候補（ラーメン・イタリア料理・カフェ など）から選ぶか自由入力 |
| 電話番号 | 指定なし／あり／なし |
| 抽出対象 | **オンライン注文あり・Uber Eatsなし**（既定）／注文ボタンが無い店も含む |
| 調査する店舗数の上限 | 1店舗あたり数秒かかります |

「抽出開始」→ 結果が表に追加されていきます。終わったら「CSVダウンロード」（Excel でそのまま開けます）。

### コマンドで使う

```bash
# 引数なしなら番号で選ぶ対話モード
python3 cli.py

# 条件を指定して実行
python3 cli.py --pref 東京都 --city 豊島区 --category イタリア料理 --phone with --limit 150
```

### 判定のしかた

1. 「{業種} {都道府県}{市区町村}」で Google マップを検索し、結果一覧を最後までスクロールして店舗を集める
2. 各店舗ページで店名・業種・住所・電話番号・評価を読む
3. 「オンラインで注文」を開き、**宅配・受け取りの両方**の「注文可能プロバイダ」を確認
4. Uber Eats が無く、電話番号・地域の条件に合う店だけを出力

### 注意

- Google マップの検索結果は1回の検索で最大120件前後です。多く集めたいときは市区町村や業種を細かく分けて実行してください。
- Google マップの画面が変わると取得できなくなることがあります。その場合は「ブラウザ画面を表示」にチェックを入れて動きを確認してください。
- Google の利用規約は自動取得を制限しています。短時間に大量実行しない（上限件数を控えめにする）など、自己責任で節度を持って利用してください。

## 2. 食べログ：新規オープン店の毎日抽出

### 仕組み

- 毎朝 **8:00（日本時間）** に GitHub Actions が `tools/tabelog_newopen/newopen.py` を実行します（GitHub 側の混雑で数分〜十数分遅れることがあります）。
- 食べログの「ニューオープン」一覧（新着順）から店舗を集め、各店舗ページの **オープン日** が直近30日以内の店を抽出します。
- 結果は `data/tabelog_newopen/YYYY-MM-DD.csv` に保存・コミットされます（発見日・オープン日・店名・ジャンル・電話番号・住所・評価・URL）。
- 一度出力した店は `seen.json` に記録し、翌日以降は出しません。**毎日のCSVには、その日に新しく見つかった店だけ**が並びます。
- 新しい店が無かった日はCSVを作りません。

### 設定（`tools/tabelog_newopen/config.json`）

| キー | 内容 | 既定 |
|---|---|---|
| `areas` | 食べログの都道府県名（URL の `tabelog.com/◯◯/` の部分）。例: `tokyo`, `kanagawa`, `osaka`, `aichi`, `fukuoka` | `["tokyo"]` |
| `pages` | 1エリアあたり読む一覧ページ数（1ページ20件） | `3` |
| `days` | オープン日が何日前までの店を対象にするか | `30` |
| `phone` | 電話番号 `any`（指定なし）／`with`（あり）／`without`（なし） | `any` |

### 有効にする

スケジュール実行は **main ブランチに取り込まれてから** 動き始めます。GitHub の Actions 画面 →「食べログ新規オープン店の抽出」→「Run workflow」で、すぐに手動実行して動作を確認できます。

### 注意

- 食べログ側が GitHub のサーバーからのアクセスを拒否した場合（ログに `HTTP 403` など）、自分のPCで実行してください。
  Mac/Linux なら `crontab -e` に次の1行を追加すると毎朝8時に実行されます。
  ```
  0 8 * * * cd /path/to/admin && python3 tools/tabelog_newopen/newopen.py
  ```
- 食べログの利用規約・サーバー負荷に配慮し、1リクエストごとに1.5〜3秒待つようにしています。`pages` を大きくしすぎないでください。
