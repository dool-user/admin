# review.md（出す前の点検）

原稿・SNS 投稿案を出す前に全部確かめる。1つでも ✗ なら直してから出す。

- [ ] 実績・数字はすべて `knowledge.md` にあるか、社長が確認したもの（`【社長確認】` が残っていない）
- [ ] 無料部分だけでも読者に役立つことが1つある
- [ ] `--- ここから有料 ---` があり、有料部分に目次どおりの中身がある
- [ ] `ng-words.md` の言葉・誇大な表現がない
- [ ] 他人の文章・画像をそのまま使っていない。引用には出典がある
- [ ] 個人情報・取引先名・APIキーなどが入っていない
- [ ] SNS 投稿案に、事実でない期限や煽りがない
- [ ] 出典が1つだけの話（まとめ記事・業者ブログだけ）は、公式ページで確かめるまで題名・本文に使っていない（10/1 追加）

## 見た目（10/1 社長の指示）
- [ ] 見出し画像（header.png）が必ずある。絵は本題に近いもの（`tools/build_note_images.py` がタイトルの言葉で選ぶ。合わなければ `tools/note_scenes.py` の RULES を直す）
- [ ] スマホで読みやすい：1文を短く（目安40字まで）、1段落は2文まで。公開用の本文（`tools/build_note_publish.py`）は1文ごとに改行し、2文ごとに段落を分ける
