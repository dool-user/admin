## ① 引越し相談フォームを公開して、note の下書きに入れる

```
これから2つの作業をお願いします。次の3か所では、必ず止まって私に確認してください：
「Google の権限の承認」「デプロイ」「note の公開・投稿」。パスワードの入力が必要になったら、私に代わってもらってください。

【作業1】引越し相談フォームを Google Apps Script で公開する
1. 新しいタブで https://sheets.new を開き、スプレッドシートの名前を「まるっと窓口 相談」にする
2. メニューの「拡張機能」→「Apps Script」を開く。プロジェクト名を「まるっと窓口 相談フォーム」にする
3. 別のタブで次を開き、表示された中身を全部コピーする：
   https://github.com/dool-user/admin/raw/claude/call-center-dashboard-mruqz7/gas/consult-form-receiver.gs
   （開けないときは https://github.com/dool-user/admin/blob/claude/call-center-dashboard-mruqz7/gas/consult-form-receiver.gs の「Raw」ボタン）
4. Apps Script の「コード.gs」の中身を全部消して、3 を貼る
5. 「var NOTIFY_TO = 'notify@example.com';」の notify@example.com を、相談の通知を受けるメールアドレスに変える（どのアドレスにするか私に聞く）
6. 左の「ファイル」の「＋」→「HTML」を選び、名前を moving-form にする（.html は自動で付く）
7. 別のタブで次を開き、中身を全部コピーして、moving-form.html の中身を全部消してから貼る：
   https://github.com/dool-user/admin/raw/claude/call-center-dashboard-mruqz7/moving-form/index.html
8. 保存（Ctrl+S または保存ボタン）
9. 右上の「デプロイ」→「新しいデプロイ」→ 歯車で「ウェブアプリ」を選ぶ
   ・説明：引越し相談フォーム
   ・次のユーザーとして実行：自分
   ・アクセスできるユーザー：全員
   ここで止まって私に確認。OK が出たら「デプロイ」→ 権限の承認（ここも私が操作します）
10. 表示された「ウェブアプリの URL」（https://script.google.com/macros/s/…/exec）をコピーして、私に見せる
11. その URL を新しいタブで開き、フォームが表示されることを確かめる（送信はしない）

【作業2】note の下書きにフォームを入れる
1. https://editor.note.com/notes/n3107470e7243/edit/ を開く
2. 本文のいちばん最後に移動する。ハッシュタグ（#〜）の行があれば、その行の上に入れる
3. 次の順で入れる（〈URL〉は作業1の10の URL）
   ・「＋」→「大見出し」：引越しのこと、まとめて相談できます
   ・本文：お部屋探し・電気ガス水道・ネット回線・ウォーターサーバー・引越し業者まで、まとめて無料でご相談いただけます。
   ・本文：※紹介するサービスによって、当社が紹介料を受け取る場合があります。
   ・本文：▼ 引越しの無料相談フォーム（2分ほどで送れます）
   ・URL だけの行：〈URL〉?src=n3107470e7243
     貼ったあとに Enter を押して、リンクのカードになったか確かめる
4. 「下書き保存」を押して止まる。画面を私に見せて確認をもらう
5. 最後に、作業1の URL をもう一度教えて（Claude Code のチャットに貼るため）
```
