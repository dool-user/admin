# Instagram DM で店舗に嫌われない書き方

**こんな人向け**
飲食店・美容室・整骨院などの店舗に、Instagram の DM で営業している人。
送っても無視される、ブロックされないか心配な人。

**この記事でできること**
店のオーナーに「しつこい業者」と思われない DM の書き方が分かります。
5行の型、店の投稿の触れ方、言わないこと、再送のルール、そのまま使える文例を載せています。

**筆者がやったこと**
店舗向けに MEO対策ツールを案内する営業で、DM の文面を AI に作らせ、別の AI に点検させ、人が1件ずつ送る仕組みを作りました。
この記事のルールは、その点検リストから取っています。

---

## 店の DM は、どう読まれているか

店の Instagram には、お客さんからの予約や質問が届きます。
そこに営業の DM が混ざります。

オーナーが営業 DM を嫌うのは、だいたい次のときです。

- 長い。スマホの画面をスクロールしないと終わらない
- どの店にも同じ文を送っているのが分かる
- 1通目から URL や資料が貼ってある
- 返事をしないと、何度も送ってくる

**DM は「お客さんの連絡が届く場所」に入っていく営業です。
**
フォームやメールより、相手の場所に近い。
だから短く、丁寧に、1回で引くのが基本です。

## 結論：5行・URLなし・投稿は1つだけ・再送は1回

1. **5行まで。** スマホで1画面に収める
2. **1通目に URL を貼らない。** 資料も送らない
3. **店の実際の投稿に1つだけ触れる。** 見ていないことは書かない
4. **断り方を書く。**「ご興味がなければスルーで大丈夫です」
5. **再送は1回まで。1週間以上あける。** 断られたら、もう送らない

**無料部分のまとめ（ここだけでも使えます）**
- 1通目の目的は「売ること」ではなく「15分だけ話を聞いてもらえるか」
- 「投稿を拝見しました」だけでは足りない。どの投稿かを1つ書く
- 自動で大量に送る仕組みは使わない。人が1件ずつ送る

### 有料部分の目次
1. 5行の型と、1行ずつの書き方
2. URL を貼らない理由と、資料を渡すタイミング
3. 店の実際の投稿の触れ方（よい例・だめな例）
4. 言わないことの一覧（代わりの言い方つき）
5. 再送のルールと、返事が来たあと
6. 自動送信をすすめない理由（Instagram の仕組みと規約）
7. 業種別の文例（飲食・美容・整骨院）
8. 送る前の点検リスト

## 1. 5行の型

```
1行目：名乗り（会社名・名前）
2行目：この店に送った理由（実際に見た投稿を1つ）
3行目：お願い（「15分だけご紹介させていただけないでしょうか」）
4行目：断り方（「ご興味がなければ、このままスルーしていただいて大丈夫です」）
5行目：（なくてもよい）お礼の一言
```

**1行ずつのコツ**
- **1行目**：「はじめまして、{会社名}の{名前}です。」だけ。会社の説明は書かない
- **2行目**：ここだけが、その店あての部分です。一番時間をかけます
- **3行目**：お願いは小さく。「契約」「導入」ではなく「15分」
- **4行目**：断り方があると、相手は安心して読めます。返事をしない自由を先に渡します
- **「突然のご連絡失礼いたします」は1回まで。** 何度も謝ると長くなるだけです

5行に収まらないときは、2行目を短くするのではなく、ほかの行を削ります。

## 2. URL を貼らない理由

1通目には URL を貼りません。
資料や画像も送りません。

- 知らない相手からの URL は、開くのが怖い
- URL があると「宣伝の DM」に見えやすい
- 読む前に「押すかどうか」を迷わせてしまう

**資料を渡すのは、相手が「詳しく知りたい」と返事をくれてから**です。
そのときも、まず1枚だけにします。

## 3. 店の実際の投稿の触れ方

2行目は、その店の投稿を実際に見て書きます。

### 見るところ
- 最近の投稿のメニュー・施術・商品
- 新しくオープンした、移転した、などのお知らせ
- 季節の限定メニューやイベント

### よい例
```
{店名}さんの、秋限定の{メニュー名}の投稿を拝見してご連絡しました。
```
```
{エリア}に新しくオープンされたとの投稿を拝見してご連絡しました。
```

### だめな例
```
素敵な投稿をいつも拝見しています。
```
→ どの店にも送れる文です。
見ていないのが伝わります。

「いつも」も事実でなければ書きません。

```
フォロワーが少なくて、もったいないと思いました。
```
→ 店の弱みを指摘する書き方は、上から目線に聞こえます。

**ルール**
- 触れる投稿は1つだけ。たくさん褒めると、かえって作り物に見えます
- 見ていないこと、推測したことは書かない（「人気のお店と伺いました」など）
- 投稿の文章や写真を、そのまま DM に貼らない。どの投稿かが分かる一言で十分です
- AI に書かせるときは、実際に見た投稿の内容を人が渡す。AI に想像で書かせない

## 4. 言わないことの一覧

- **必ず来店が増えます／絶対儲かります**　理由・代わりに：「来店を増やす方法の1つとしてご案内しています」
- **1位にします・上位表示を保証**　理由・代わりに：順位は Google が決めます。保証はできません
- **口コミを増やします・★5を集めます**　理由・代わりに：見返り付きの口コミ集めを思わせます。Google のポリシー違反の手法を連想させるので使いません
- **Google公認・Google提携**　理由・代わりに：事実でなければ使いません
- **今だけ・本日中に**　理由・代わりに：事実の期限がないなら書きません
- **無料診断**　理由・代わりに：業者の決まり文句に見えます
- **皆さんやってます**　理由・代わりに：事実で確かめられるときだけ、具体的に
- **至急ご返信ください／ご返信がない場合は…**　理由・代わりに：返信は相手の自由。使いません
- **「このままだと表示されなくなります」**　理由・代わりに：不安をあおる書き方はしません
- **競合店の悪口**　理由・代わりに：使いません

ほかに、**1通目で料金・契約の話をしない**ことも決めています。
まだ話を聞くと決めていない相手に、お金の話は早すぎます。

## 5. 再送のルールと、返事が来たあと

### 再送
- **返事がないとき**：再送は1回まで。1週間以上あける
- 再送は同じ文を送らない。短く、「先日ご連絡した{名前}です」から始める
- **断られたとき**：お礼だけ返して、以後送らない
- 同じ店に30日以内に送っていないか、送る前に一覧で確かめる

再送の文例です。

```
先日ご連絡した、{会社名}の{名前}です。
Googleマップからのご来店を増やすツールを、15分だけご紹介できればと思い、もう一度だけご連絡しました。
ご興味がなければ、このままで大丈夫です。今後はお送りしません。
```

### 返事が来たら
- **興味あり** → 日程を2つ出して返す。その日のうちに返す
- **検討中** → 資料は1枚だけ。「1週間後にもう一度ご連絡してもよいですか」と聞く
- **お断り** → 「お忙しいところありがとうございました」で終える

## 6. 自動送信をすすめない理由

DM を自動でたくさん送りたくなるかもしれません。
私たちは、すすめません。
人が1件ずつ送っています。

**Instagram の公式の仕組み（API）では、企業から自由に DM を送れるわけではありません。
**
基本は、相手から先にメッセージが届いたときに、その後24時間以内に返信できる、という形です。
つまり、こちらから知らない店に1通目を送る用途には、公式の仕組みは向いていません。

公式でないツールで自動送信すると、Instagram の規約に反するおそれがあります。
アカウントが制限されることも考えられます。
手で送る場合も、短い時間に大量に送る使い方は避けてください。

ルールは変わることがあります。
**使う前に、Meta の最新のポリシーを必ず確認してください。

**
- Meta Messenger Platform のポリシー：https://developers.facebook.com/documentation/business-messaging/messenger-platform/policy

私たちの送り方はこうです。
- AI が文面を作り、別の AI が点検して「承認済」にする
- 送信補助ツールは、店のプロフィールを開いて文面を画面に出すだけ
- 人が文面を読み、コピーして DM に貼り、人が送る
- 1日に送る上限を決めておく

※規約・法律の判断は、必要に応じて専門家に確認してください。

## 7. 業種別の文例

どれも、`{ }` の中は実際に見た事実だけで埋めます。

### 飲食店
```
はじめまして、{会社名}の{名前}です。
{店名}さんの{メニュー名}の投稿を拝見してご連絡しました。
Googleマップからのご来店を増やすためのツールを、15分だけご紹介させていただけないでしょうか。
ご興味がなければ、このままスルーしていただいて大丈夫です。
```

### 美容室・サロン
```
はじめまして、{会社名}の{名前}です。
{店名}さんの{施術名}のスタイル写真の投稿を拝見してご連絡しました。
Googleマップで見つけてもらいやすくするツールを、15分だけご紹介させていただけないでしょうか。
ご興味がなければ、このままスルーしていただいて大丈夫です。
```

### 整骨院
```
はじめまして、{会社名}の{名前}です。
{店名}さんが{エリア}に新しく開院されたとの投稿を拝見してご連絡しました。
Googleマップで近くの方に見つけてもらうためのツールを、15分だけご紹介させていただけないでしょうか。
ご興味がなければ、このままスルーしていただいて大丈夫です。
```

## 8. 送る前の点検リスト

```
- [ ] プロフィールに「営業お断り」「セールスご遠慮」などの表記がない
- [ ] 同じ店に、この30日で送っていない
- [ ] 5行以内。URL・資料を貼っていない
- [ ] 名乗り（会社名・名前）がある
- [ ] 触れた投稿は1つで、実際に見たもの
- [ ] 断り方が書いてある
- [ ] 1通目で料金・契約の話をしていない
- [ ] 上の「言わないこと」を使っていない
- [ ] 不安をあおる書き方をしていない
- [ ] 再送なら、前回から1週間以上あいていて、1回目の再送である
- [ ] 送るのは人。自動送信ツールを使っていない
```
