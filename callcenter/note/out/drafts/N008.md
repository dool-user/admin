# やってはいけない口コミ集め：Google のルールと安全な頼み方

**こんな人向け：** 美容室・整骨院・飲食店などの店長やオーナー。口コミを増やしたいけれど、どこまでが OK で、どこからが違反なのか分からない人。

**この記事でできること：** Google が禁止している口コミの集め方が分かります。見返りなしで頼むときの、そのまま使える声かけ・POP・LINE の文面が手に入ります。悪い口コミへの返し方と、嘘っぽい口コミを見つけたときの動き方も分かります。

**筆者について：** 店舗向けに MEO（Googleマップ集客）のツールを案内する仕事をしています。【社長確認：MEO に関わった期間・担当した店舗の数など、確認できる事実だけ】

## 口コミは「集め方」で損をする

口コミは、Googleマップでお店を選ぶ人がよく見る場所です。
だから「早く増やしたい」と思うのは自然です。

ただ、集め方をまちがえると逆効果です。
Google は、ルールに合わない口コミを削除します。
違反が重なると、プロフィールそのものに制限がかかることもあります（[Google ビジネス プロフィールのポリシーの概要](https://support.google.com/business/answer/13762416?hl=ja)）。

## やってはいけない4つ（ここだけ覚えてください）

Google マップの口コミのルールは「[禁止および制限されているコンテンツ](https://support.google.com/contributionpolicy/answer/7400114?hl=ja)」というページにまとまっています。
そこでは、実際の体験にもとづかない口コミを「虚偽のエンゲージメント」と呼んで禁止しています。

お店の側でよく起きるのは、次の4つです。

1. **見返りをつける**：「口コミを書いたら1品サービス」「★5で次回割引」など
2. **嘘の口コミを書く・書かせる**：来ていない人の口コミ、1人で何個も書く口コミ
3. **家族・スタッフに書かせる**：利害関係のある人の口コミは禁止
4. **代行業者に頼む**：お金を払って口コミを書いてもらうこと

どれも「悪気がなかった」では通りません。
迷ったら、**見返りなし・実際に来た人だけ・書くかどうかはお客さんの自由**。この3つで判断してください。

## 安全な頼み方は「一言だけ、見返りなし」

Google のヘルプでも、お客さんにリンクや QR コードを渡して口コミをお願いする方法が紹介されています（[クチコミを増やすためのヒント](https://support.google.com/business/answer/3474122?hl=ja)）。
頼むこと自体は問題ありません。問題になるのは、見返りや、書く中身の指定です。

**無料部分のまとめ（ここだけでも使えます）**
- 見返り・嘘・家族スタッフ・代行業者の4つはやらない
- 頼むときは「よろしければ」と一言。見返りはつけない
- 良い口コミだけを選んで頼まない

## 1. 違反になる例・ならない例（早見表）

| やりがちなこと | 判断 | 理由 |
|---|---|---|
| 「口コミを書いてくれたらドリンク1杯無料」 | ✕ | 見返りをつけている |
| 「★5をつけてくれたら次回10%オフ」 | ✕ | 見返り＋評価の指定 |
| 満足していそうな人にだけ頼む | ✕ | 良い口コミだけを選んで集めるのは禁止 |
| スタッフが自分のスマホで口コミを書く | ✕ | 利害関係がある |
| 家族や友人に「書いておいて」と頼む | ✕ | 利害関係がある。来ていない人なら嘘の口コミにもなる |
| 業者に「口コミ〇件」を頼む | ✕ | お金を払って書かせている |
| 悪い口コミを消してくれたら返金する、と持ちかける | ✕ | 口コミの修正と引き換えに見返りを渡している |
| 会計のときに「よろしければ」と QR コードを渡す | ○ | 見返りなし・任意 |
| レシートやお礼のメッセージにリンクをのせる | ○ | Google のヘルプでも紹介されている方法 |
| 全部の口コミに返信する | ○ | 良い口コミにも悪い口コミにも返す |

ポイントは2つです。
**「書いたら何かもらえる」をなくすこと。** そして **「書く人を選ばないこと」。**

「良い口コミだけを選んで頼む」のは、うっかりやりがちです。
満足そうなお客さんにだけ声をかける、アンケートで高い点をつけた人だけに Google のリンクを出す、といったやり方です。
頼むなら、来てくれた人みんなに同じように頼みます。

## 2. そのまま使える文面

### 会計時の声かけ

```
本日はありがとうございました。
もしよろしければ、Googleマップにご感想をいただけると励みになります。
こちらの QR コードから書けます。もちろん、無理にとは言いません。
```

言い方のコツは3つです。
- 「よろしければ」「無理にとは」を入れる（書くかどうかはお客さんの自由）
- 「★5で」「良いことを」など、評価や中身を指定しない
- 断られても、表情を変えない

### 店内 POP（レジ横・テーブル）

```
ご感想をお聞かせください

Googleマップでのご感想は、
これから来られる方の参考になります。
良かったことも、直してほしいことも、
そのまま書いていただけるとうれしいです。

（QR コード）
```

「直してほしいことも」と書いておくと、良い口コミだけを求めている印象になりません。
POP に「プレゼント」「割引」の文字は入れません。

### LINE（来店後のお礼）

```
〇〇様
本日はご来店ありがとうございました。
もしよろしければ、Googleマップにご感想をいただけるとうれしいです。
▼こちらから書けます
（リンク）
今後ともよろしくお願いいたします。
```

LINE のクーポン配信と同じメッセージに入れないようにします。
並べて送ると、「口コミを書いたらクーポン」と受け取られるおそれがあります。

リンクや QR コードの作り方は、Google の公式ヘルプで手順を確認してください（[リンクまたは QR コードを作成してクチコミをリクエストする](https://support.google.com/business/answer/16816815?hl=ja)）。

## 3. 悪い口コミへの返し方

悪い口コミへの返信は、書いた本人だけでなく、**これから来る人が読んでいます。**
言い返すより、「このお店はちゃんと対応してくれそう」と思ってもらうほうが大事です。

### 返信の型（4行）
1. お礼：来てくれたこと、書いてくれたことへのお礼
2. おわび：嫌な思いをさせたことへのおわび（事実を認められる範囲で）
3. これから：何を直すか、または確認すること
4. 連絡先：くわしく聞きたいときの窓口（必要なときだけ）

### 例文（待ち時間が長かった、という口コミ）

```
ご来店いただき、またご感想をお寄せいただきありがとうございます。
お待たせしてしまい、申し訳ございませんでした。
ご予約の入れ方と、お待ちいただくときのご案内を見直します。
またお越しいただけた際には、気持ちよくお過ごしいただけるよう努めます。
```

### 返信でやらないこと
- お客さんの名前・来店日・施術内容など、個人が分かることを書く
- 「そんな事実はありません」と言い切って責める
- 「消してくれたら〇〇します」と持ちかける（見返りになる）
- 感情的になったまま、その日のうちに返す

すぐに返したくなったら、一晩おいてから、別の人に読んでもらってください。

## 4. 嘘っぽい口コミを見つけたとき

来た記録がない人の口コミや、同じような文の悪い口コミが続く、ということもあります。

### まずやること
1. **消そうとしない・言い返さない**：口コミに感情的な返信をつけない
2. **記録を残す**：口コミの画面を保存し、投稿日・内容・気づいたことをメモする
3. **ルールに当たるか確認する**：「[禁止および制限されているコンテンツ](https://support.google.com/contributionpolicy/answer/7400114?hl=ja)」のどれに当たりそうかを見る。「低い評価だから」「内容が気に入らないから」だけでは、ルール違反にはならない
4. **Google に報告する**：ビジネスプロフィールの管理画面や Google マップから、ポリシー違反の口コミとして報告できます。**操作の手順は画面が変わることがあるため、公式ヘルプで手順を確認してください**（[ビジネス プロフィール上の不適切なクチコミを報告する](https://support.google.com/business/answer/4596773?hl=ja)／[クチコミの管理](https://support.google.com/business/workflow/9945796?hl=ja)）
5. **報告の結果を確認する**：報告した口コミがどうなったかも、公式ヘルプの案内に沿って確認します

報告しても、必ず消えるわけではありません。
消えなかったときは、落ち着いた返信を1つつけておくほうが、読む人には伝わります。

脅しや個人情報が書かれているなど、お店だけで抱えられないときは、弁護士などの専門家に相談してください。

## 5. 広告のルール（ステマ規制）にも気をつける

Google のルールとは別に、日本の法律の話もあります。
2023年10月1日から、広告なのに広告だと分からない表示（いわゆるステルスマーケティング）は、景品表示法の不当表示として規制されています（[消費者庁：令和5年10月1日からステルスマーケティングは景品表示法違反となります](https://www.caa.go.jp/policies/policy/representation/fair_labeling/stealth_marketing)）。

消費者庁の説明では、SNS の投稿やレビュー投稿も対象になりうるとされています。
お店がお金や物を渡して、お客さんのふりをした投稿をしてもらう、といったことは避けてください。

ここは一般的な注意です。
自分のお店のやり方が当たるかどうか迷ったら、消費者庁のページを読むか、専門家に確認してください。

## 6. お店で共有するチェックリスト

スタッフ全員で同じやり方にするために、印刷して貼っておけます。

```
- [ ] 口コミのお願いに、割引・プレゼント・ポイントをつけていない
- [ ] 「★5で」「良いことを書いて」と言っていない
- [ ] 満足していそうな人だけに頼んでいない（全員に同じように頼む）
- [ ] スタッフ・家族・知人が、うちの店の口コミを書いていない
- [ ] 口コミを書く業者に頼んでいない
- [ ] POP・LINE に、クーポンと口コミのお願いを並べていない
- [ ] 悪い口コミにも、4行の型で返信している
- [ ] 返信に、お客さんの個人情報を書いていない
- [ ] 嘘っぽい口コミは、記録を残してから公式ヘルプの手順で報告している
```
