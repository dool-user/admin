# 春の新生活でネットが間に合わない…を防ぐ：繁忙期の回線・電気・ガス・水・ウォーターサーバーを申し込む順番

**こんな人向け：** 1〜3月に引越す予定の人。進学・就職・転勤で、3月の後半に新生活が始まる人。電気・ガス・水道・ネット・ウォーターサーバーを、どれから申し込めばいいか迷っている人。

**この記事で分かること：** 春の繁忙期に、ライフラインとネットを申し込む順番。順番をそう決める理由。新居が決まった日から入居の日までの逆算のしかた。

**結論：** 新居が決まったら、**①ネット回線 → ②ガスの開栓の予約 → ③電気 → ④水道 → ⑤ウォーターサーバー → ⑥旧居の解約・返却** の順で連絡します。「人が来る日を予約するもの」から先に押さえるのがコツです。今日1件目に電話すれば、まだ間に合います。

---

## なぜ春は「順番」が大事なのか

国土交通省は毎年、引越しの依頼が3〜4月に集中するとして、引越しの時期をずらす協力を呼びかけています。報道発表のタイトルでは「3月の引越件数は通常月の約2倍」と案内しています（出典は最後の確認リスト）。

引越しが集中すると、混むのは引越し業者だけではありません。新居で「誰かが来て作業する日」を予約する手続きも、同じ時期に申し込みが重なります。

- **ネット回線の開通工事**：工事の人が来る日を予約する
- **ガスの開栓**：係の人が来て、立ち会いのもとで開栓する
- **ウォーターサーバーの設置・配送**：サーバーや水を届けてもらう日を決める

たとえばソフトバンク光は、公式ページで、2〜4月の引越しシーズンは手続きが混み合い、希望の工事日にそえないことがあると案内しています。ほかの回線でも、時期によって工事日が先になることがあります。

一方で、電気や水道は、多くの物件で立ち会いなしで使い始められます。だから、**予約の枠が埋まりやすいものから先に申し込む**のが、春の引越しの順番の考え方です。

## 申し込む順番と、その理由

### ① ネット回線（新居が決まった日のうちに）
いちばん先に動くのはネットです。理由は2つあります。

1. 工事が要る場合、工事日は事業者の予定に合わせて決まる
2. 建物の設備によって、使える回線そのものが変わる

まず管理会社に「建物にどの回線の設備があるか」を聞き、そのうえで申し込む回線を決めます（聞くことの詳しい中身は、別の記事「引越し先のネットが使えない…を防ぐ：回線の申込はいつ・何を確かめるか」にまとめています）。

フレッツ光・ドコモ光・auひかり・ソフトバンク光など、どの回線でも、**開通までの目安と、いつから申し込みを受け付けているかは、各社の公式ページで確かめて**ください。目安は時期や建物で変わるので、この記事では日数を書いていません。

今の回線を新居でも続ける（移転する）場合も、移転の手続きで新居の工事日を決めます。考え方は新しく申し込むときと同じで、早いほど選べる日が増えます。

### ② ガスの開栓の予約（ネットと同じ週に）
ガスは、新居で使い始めるときに立ち会いが必要になるのが一般的です。立ち会いの日時は、希望どおりに取れるとは限りません。

入居の日の夜にお風呂に入りたいなら、**入居の日か、その翌日の枠**を先に押さえます。引越し業者の作業時間と重ならないよう、作業が終わる見込みの時間より後で予約すると安心です。

### ③ 電気（ガスの予約のあと、早めに）
電気は、スマートメーターが付いている物件なら、多くの場合、立ち会いなしで使用開始の処理ができます。ただ、申し込みを忘れると入居の夜に明かりがつきません。

引越しは、電力会社や料金プランを見直しやすいタイミングでもあります。選び直す場合は、料金や契約の条件を各社の公式サイトで確かめてから決めます。迷う時間が長くなりそうなら、**まず使用開始の申し込みだけ先に済ませる**のも手です。

### ④ 水道（新居の地域の水道局に）
水道は、新居の住所を担当する水道局に申し込みます。多くの物件では立ち会いは要りませんが、申し込みの締め切りや方法は水道局ごとに違います。新居の市区町村のページで確かめてください。

### ⑤ ウォーターサーバー（ネットの工事日が決まってから）
今のサーバーを新居に持っていく場合は、移設の方法と、水の配送先の住所変更を事業者に伝えます。新しく申し込む場合は、置き場所と電源を新居で確かめてからにします。

順番を後ろにしているのは、**届けてもらう日を、ネットの工事やガスの立ち会いの日と分けたい**からです。入居の日に人の出入りが重なると、立ち会いの時間に遅れやすくなります。

### ⑥ 旧居の解約・撤去・機器の返却（新居の手配がそろってから）
旧居の回線の解約、撤去工事の要否、ルーターなどレンタル機器の返却、ウォーターサーバーの返却は、新居の手配がそろってから進めます。

先に旧居を止めてしまうと、新居が開通するまでネットが使えない期間ができます。**解約の日は、新居の開通日より後**に設定するのが基本です。

## 入居日から逆算する：書き込み用の表

入居の日が決まったら、下の表のように「いつ・何を」を書き出します。日付は自分の予定で埋めてください。

| 順番 | やること | 自分の予定日 |
|---|---|---|
| ① | 管理会社に回線の設備を聞き、ネットを申し込む | 新居が決まった日 |
| ② | ガスの開栓の立ち会いを予約する | ①と同じ週 |
| ③ | 電気の使用開始を申し込む | ②のあと |
| ④ | 水道の使用開始を申し込む | 水道局の締め切りまで |
| ⑤ | ウォーターサーバーの移設・配送日を決める | ①の工事日が決まってから |
| ⑥ | 旧居の解約・撤去・返却の日を決める | 新居の開通日より後 |

「もう2月の終わりで、新居も決まったばかり」という人も大丈夫です。①と②を今日のうちに申し込めば、残りは数日のうちに片づけられます。ネットの工事日が入居より後になったときは、モバイルルーターやテザリングなど、つなぎの方法を用意しておきます。

## チェックリスト：繁忙期の申し込み順

- [ ] 管理会社に、建物の回線の設備を聞いた

- [ ] ガスの開栓の立ち会いを、入居の日かその翌日に予約した
- [ ] 電気の使用開始を申し込んだ（契約先を選び直すなら公式サイトで条件を確認）
- [ ] 水道の使用開始を、新居の水道局に申し込んだ
- [ ] ウォーターサーバーの移設・配送の日を、工事・立ち会いと重ならない日にした
- [ ] 旧居の回線の解約日を、新居の開通日より後にした
- [ ] レンタル機器・サーバーの返し方と期限を確かめた
- [ ] 工事日が入居より後なら、つなぎの方法を決めた

## よくある失敗

**1. 電気から手をつけて、ネットの工事日が先になる**
いちばん分かりやすい電気から申し込み、ネットを後回しにする例です。電気は立ち会いが要らないことが多いので、順番は後でも間に合いやすいです。人が来るものから先に押さえます。

**2. 旧居の回線を先に解約して、ネットのない期間ができる**
「引越すから解約」と先に止めてしまい、新居の開通まで家でネットが使えない例です。解約の日は、新居の開通日を確かめてから決めます。

**3. 入居の日に、工事・ガス・配送を全部入れてしまう**
一日で片づけようとして、引越し業者の作業が延びたときに立ち会いに間に合わない例です。時間帯を分けるか、日を分けておきます。

## 引越しのこと、まとめて相談できます

春の引越しで、ネットとライフラインの申し込みをまとめて進めたい方は、筆者の会社にご相談ください。インターネット回線は、フレッツ光・ドコモ光・auひかり・ソフトバンク光などの中から、新居の建物で使える回線をご案内します（建物やエリアによって使えない回線があります）。電気・ガス・水道は「でんき開通サポート」（関東1都6県：東京・神奈川・埼玉・千葉・茨城・群馬・栃木）で、新居の電気の使用開始のお申し込みを取り次ぎ、ガス・水道・インターネットのお申し込みもあわせてお預かりします。電力会社・ガス会社・水道局の公式窓口ではなく、民間の取次サービスです。
でんき開通サポート：【社長確認：LPのURL】

筆者の会社では、引越しにまつわる次のご相談をまとめて受けています。
- インターネット回線
- 電気・ガス・水道の手続き
- ウォーターサーバー
- お部屋探し（提携する不動産会社をご紹介します。物件のご案内・契約・仲介は提携先の不動産会社が行います【社長確認：提携先の不動産会社名と宅建業の免許番号】）
- 関東の引越し業者のご紹介
