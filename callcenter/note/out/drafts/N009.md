# MEO 業者に頼む前に確認する7つのこと

**こんな人向け：** 美容室・整骨院・飲食店などの店長やオーナー。MEO（Googleマップ集客）の業者から営業を受けていて、契約してよいか迷っている人。

**この記事でできること：** 契約の前に業者へ聞くべき7つの質問と、返ってきた答えの見方が分かります。そのまま使える質問リストと、断るときの文面も手に入ります。

**筆者について：** 【社長確認：筆者は MEO ツールを扱う会社にいる。この立場を読者にどう書くか（会社名を出すか・担当した期間など、確認できる事実だけ）】

---

## 先にお伝えしておくこと

筆者は MEO ツールを扱う会社にいます（上の【社長確認】で書き方を決めます）。
なので、この記事では **特定の業者やツールをすすめません。** 自社の紹介もしません。
「頼まずに自分でやる」も、同じくらいまっとうな選択肢として書きます。

## 業者選びで困るのは「あとから分かる」こと

MEO の業者は、Googleビジネスプロフィール（Googleマップに出るお店の情報）の手入れを代わりにやってくれます。
うまく使えば、手間が減ります。

困るのは、契約してから分かることです。
「解約できない」「プロフィールが自分で触れない」「何をしてくれているのか分からない」。
どれも、**契約の前に聞いておけば防げる**ことです。

## 確認する7つのこと（見出しだけ）

1. 順位を「保証」していないか
2. 口コミをどうやって集めるのか
3. 契約期間と、解約の条件
4. プロフィールのオーナー権限を誰が持つか
5. 月額に何が含まれているか
6. 報告の中身は何か
7. Google のルールに違反したとき、誰が責任を持つか

この中で、**一番大事なのは4番です。** オーナー権限は、お店のあなたが持ち続けてください。

## 1つだけ先に：順位の保証は、うたってはいけないこと

Google は、代わりにプロフィールを管理する会社（サードパーティ）向けのルールを出しています。
その中で、**Google での上位掲載を保証することは禁止**とされています（[ビジネス プロフィールのサードパーティ ポリシー](https://support.google.com/business/answer/7353941?hl=ja)）。

順位は Google が決めます。誰にも保証はできません。
「必ず1位」「上位表示を保証」と言われたら、そこで一度立ち止まってください。

**無料部分のまとめ（ここだけでも使えます）**
- 順位の保証をうたう業者は、Google のルールに合っていない
- オーナー権限はお店が持ち続ける
- 契約の前に、解約の条件と月額の中身を紙で確認する

## 1. 7つの質問と、答えの見方

### ① 順位を「保証」していないか

**聞くこと：** 「順位について、どんな約束をしていますか」

**見方：**
- ○「順位は Google が決めるので保証はできません。やることは〇〇です」
- ✕「必ず上位に出します」「上がらなければ返金」

返金の約束があっても、保証をうたっていることに変わりはありません。
サードパーティのポリシーでは、特別な手段で順位を約束したり操作したりすることも認められていません（[サードパーティ ポリシー](https://support.google.com/business/answer/7353941?hl=ja)）。

### ② 口コミをどうやって集めるのか

**聞くこと：** 「口コミは、どんな方法で増やしますか。文面を見せてもらえますか」

**見方：**
- ○ お客さんに見返りなしでお願いする文面・QR コードを用意する
- ✕「〇件増やします」「★5を集めます」
- ✕ 割引や特典と引きかえに書いてもらう
- ✕ 業者側の人が書く

Google マップのルールでは、見返りと引きかえの口コミ、実際の体験にもとづかない口コミ、利害関係のある人の口コミは禁止です（[禁止および制限されているコンテンツ](https://support.google.com/contributionpolicy/answer/7400114?hl=ja)）。
違反した口コミは削除され、プロフィールに制限がかかることもあります（[ポリシーの概要](https://support.google.com/business/answer/13762416?hl=ja)）。
**件数を約束する業者は、どうやってその件数を出すのか**を必ず聞いてください。

### ③ 契約期間と、解約の条件

**聞くこと：** 「最低契約期間は何か月ですか。途中でやめるとき、いくらかかりますか。何日前までに、どうやって伝えればいいですか」

**見方：**
- ○ 期間・解約金・連絡方法が、契約書に書いてある
- ✕ 口頭の説明だけで、書面がない
- ✕ 自動で更新されるのに、そのことが説明されない

「いつでもやめられます」と言われたら、**それが契約書のどこに書いてあるか**を指で示してもらいます。

### ④ オーナー権限を誰が持つか

**聞くこと：** 「プロフィールのオーナーは誰になりますか。御社にはどの権限を渡せばいいですか」

**見方：**
- ○ お店がオーナーのまま。業者には「管理者」の権限を渡す
- ✕ 業者のアカウントを「メインのオーナー」にする
- ✕ お店の Google アカウントのパスワードを教えてほしいと言われる

Google のヘルプでは、プロフィールにはオーナーと管理者がいて、**メインのオーナーは1人だけ**とされています。
管理者は、オーナーとほぼ同じことができますが、ユーザーの追加・削除や、プロフィールの削除はできません（[オーナーと管理者を管理する](https://support.google.com/business/answer/3403100?hl=ja)）。
業者の仕事には、ふつう管理者で足ります。

### ⑤ 月額に何が含まれているか

**聞くこと：** 「月額の中で、毎月やってもらえることを全部書き出してもらえますか。別料金になるものはどれですか」

**見方：**
- ○「投稿は月〇回」「口コミの返信の代行あり・なし」など、回数と範囲が書いてある
- ✕「総合的に対策します」だけで、中身が分からない
- ✕ 初期費用・写真撮影・ツール利用料など、あとから別料金が出てくる

回数が書いていないと、何もしていない月があっても確かめられません。

### ⑥ 報告の中身は何か

**聞くこと：** 「毎月の報告書の見本を見せてもらえますか」

**見方：**
- ○ その月に **やった作業** と、Google のプロフィールで見られる数字（表示回数・電話・ルート検索など）が分かれている
- ✕ 業者が決めた言葉での「順位」だけ
- ✕ 見本を出してもらえない

順位は、調べる場所や時間、使う端末で変わります。
「どの場所から、何という言葉で調べた順位か」も聞いておきます。
プロフィールの数字は、オーナーのあなたも自分で見られます。業者の報告と見比べてください。

### ⑦ Google のルールに違反したとき、誰が責任を持つか

**聞くこと：** 「御社の作業が原因で、口コミが消えたりプロフィールが止まったりしたら、どう対応しますか」

**見方：**
- ○ 対応の中身（原因の説明・直す作業・費用の扱い）が契約書に書いてある
- ✕「そういうことは起きません」で終わる
- ✕ 責任はすべてお店、と書いてある

プロフィールが止まって困るのは、お店です。
ここを聞いて答えがはっきりしない業者は、ほかの答えも疑ってよいと思います。

## 2. 業者に送る質問リスト（コピーして使える）

メールやフォームで、このまま送れます。**答えを文字でもらう**のが大事です。

```
〇〇株式会社 〇〇様

ご案内ありがとうございます。
検討のため、次の7点を文書でお教えいただけますでしょうか。

1. 検索順位について、どのようなお約束をされていますか
2. 口コミはどのような方法で増やしますか（お客様への依頼文の見本があれば添付ください）
3. 最低契約期間・途中解約の費用・解約の連絡方法と期限
4. ビジネスプロフィールのオーナーは当店のままですか。御社に付与する権限は何ですか
5. 月額に含まれる作業（回数）と、別料金になるもの
6. 毎月の報告書の見本
7. 御社の作業が原因でプロフィールに制限がかかった場合の対応

お手数をおかけしますが、よろしくお願いいたします。
（店名・お名前）
```

## 3. オーナー権限を守る手順

1. **自分のアカウントがオーナーか確かめる**：プロフィールの設定の「ユーザーとアクセス権」の画面で、自分がオーナーになっているかを見る
2. **業者は「管理者」で追加する**：業者の Google アカウントを、管理者として招待する
3. **パスワードは渡さない**：お店の Google アカウントのログイン情報は、誰にも教えない
4. **メインのオーナーを譲らない**：業者から頼まれても、メインのオーナー権限は移さない
5. **解約したら、業者を外す**：契約が終わったら、業者のアカウントをユーザーから削除する

画面の名前や操作は変わることがあります。**細かい手順は公式ヘルプで確認してください**（[オーナーと管理者を管理する](https://support.google.com/business/answer/3403100?hl=ja)／[メインのオーナー権限を譲渡する](https://support.google.com/business/answer/3415281?hl=ja)）。

## 4. 自分でやるか、頼むかの判断

どちらが正しい、ということはありません。目安だけ書きます。

| 自分でやる向き | 頼む向き |
|---|---|
| 毎週すこしでも自分で触る時間をとれる | 手が回らず、何か月も触れていない |
| 写真や投稿を自分で出したい | 何をすればいいか整理から手伝ってほしい |
| まずお金をかけずに試したい | 7つの質問に、書面ではっきり答える業者がいる |

先に基本の手入れ（名前・業種・営業時間・写真・口コミの返信）を自分でやってみると、業者の説明が分かりやすくなります。
やってみてから決めても、遅くはありません。

## 5. 断るとき・見直すときの文面

### 断るとき

```
ご案内ありがとうございました。
検討しましたが、今回は見送らせていただきます。
今後のご連絡は控えていただけますと幸いです。
```

理由を細かく書く必要はありません。

### いま契約中で、見直したいとき

```
いつもお世話になっております。
契約内容を確認したく、次の点をお教えください。
・現在の契約期間の終わりと、解約の連絡期限
・当店のビジネスプロフィールで、御社に付与している権限
・この3か月に行った作業の一覧
```

まず、自分がオーナーのままかを先に確かめてから送ると安心です。

## チェックリスト（契約の前に）

```
- [ ] 順位の保証をうたっていない
- [ ] 口コミの集め方に、見返り・件数の約束・代筆がない
- [ ] 契約期間・解約金・解約の連絡方法が書面にある
- [ ] オーナーはお店のまま。業者は管理者
- [ ] 月額の作業の回数と、別料金のものが書面にある
- [ ] 報告書の見本を見た
- [ ] 違反が起きたときの対応が書面にある
```

質問はコメントでどうぞ。
