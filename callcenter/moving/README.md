# 引越しチーム（note A11：引越し・新生活）

引越しのお役立ちコラムを note で無料公開し、**本業のサービスの相談につなぐ** チームです。判定は note の売上ではなく、相談フォームの件数。

## 本業でできること（コラムの締めでつなぐ先）
- 物件の紹介（仲介手数料を無料にできる）
- ライフライン（電気・ガス・水道）の紹介
- インターネット回線の紹介
- ウォーターサーバーの紹介
- 関東の引越し業者の紹介

## チーム（9名・全員 Claude）
| 担当 | 名前 | エージェント |
|---|---|---|
| 編集長 | ミナト | `moving-editor` |
| リサーチ | カナデ | `moving-researcher` |
| ライター（物件・部屋探し） | アオイ | `moving-writer` |
| ライター（ライフライン・ネット・ウォーターサーバー） | リク | `moving-writer` |
| ライター（引越し作業・役所の手続き） | サヤ | `moving-writer` |
| 制度確認係 | ジン | `moving-compliance`（宅建業法・不動産の表示ルール・景品表示法・役所の手続き） |
| SNS 集客 | ヒカリ | `moving-promoter` |
| 相談受付 | モモ | `moving-intake` |
| 分析 | タイチ | `moving-analyst` |

## 流れ
リサーチ（企画）→ 編集長（割り振り）→ ライター3人（無料コラム）→ 制度確認係 → 編集長（最終点検・ストック）→ 社長が note に公開 → SNS 集客 → 相談フォーム（リポジトリ直下の `moving-form/index.html`）→ 相談受付 → 本業の担当へ → 分析（記事別の相談件数）

記事は note 事業部と同じ `note/out/drafts/` と `note/out/articles.csv`（アカウント A11）に置き、プレビュー画面にも出る。ルールとナレッジはこのフォルダ。
