# templates.md（コラムの型）

## 基本の型（無料コラム）
1. タイトル：いつ・誰が・何を（例：「引越しが決まったら最初の1週間でやること」）
2. 冒頭3行：こんな人向け／この記事で分かること／結論
3. 本文：時期順か、やること順の見出し。チェックリストを1つ入れる
4. 「よくある失敗」を2〜3個
5. 締め（下）
6. 確認リスト（公開前に消す）：出典 URL と【社長確認】

## 締め（必ず入れる）
```
## 引越しのこと、まとめて相談できます
（この記事のテーマに合うサービスを1〜2行で先に）
筆者の会社では、引越しにまつわる次のご相談をまとめて受けています。
- お部屋探し（仲介手数料を無料にできる物件があります）【社長確認：条件】
- 電気・ガス・水道の手続き
- インターネット回線
- ウォーターサーバー
- 関東の引越し業者のご紹介
※紹介するサービスによって、当社が紹介料を受け取る場合があります。【社長確認：書き方】
▶ 引越しの無料相談フォーム（URL?src=記事ID）
```

## 画像（9/30 社長の指示：類似記事にならって画像を入れる）
- 見出し画像（1920×1006・note の推奨 1280×670 と同じ比率）を全記事に付ける
- 本文には「この記事のポイント」図、「保存用チェックリスト」図、流れのある記事は図解を入れる
- 画像は `python tools/build_note_images.py <記事ID>` で作る。下書きに `![...](../images/<ID>/...png)` が差し込まれるので、note に貼るときは同じ位置に画像をアップロードする
- 図解を増やすときは `tools/build_note_images.py` の DIAGRAMS に足す
