# review.md（出す前の点検）

- [ ] 役所の手続き・期限・法律は、公式ページの出典つき
- [ ] 「仲介手数料無料」には「条件は物件によって違うため、ご相談のときにご説明します」がある
- [ ] 物件の紹介は「提携する不動産会社を通じて」と書き、提携先の会社名・宅建業の免許番号がある（未記入なら【社長確認】）
- [ ] 他社の料金・キャンペーンを断定していない
- [ ] 最後の締めがあり、「筆者の会社が紹介していること」「紹介料を受け取る場合があること」が書いてある
- [ ] 相談フォームへのリンクに `?src=記事ID` が付いている
- [ ] `ng-words.md` の言葉がない。不安をあおっていない
- [ ] 本文だけでも読者の役に立つ（チェックリストが1つある）
- [ ] 制度確認係（ジン）の「制度確認：OK」が先頭コメントにある
- [ ] 出典が1つだけの話（まとめ記事・業者ブログだけ）は、公式ページで確かめるまで使っていない（10/1 追加）

## 見た目（10/1 社長の指示）
- [ ] 見出し画像（header.png）が必ずある。絵は本題に近いもの（`tools/build_note_images.py` がタイトルの言葉で選ぶ。合わなければ `tools/note_scenes.py` の RULES を直す）
- [ ] ハッシュタグがある（`tools/note_tags.py` が無料部分の最後に入れる。公開設定のハッシュタグ欄にも入れる。誇大な言葉・他社の商標は使わない）
- [ ] スマホで読みやすい：1文を短く（目安40字まで）、1段落は2文まで。公開用の本文（`tools/build_note_publish.py`）は1文ごとに改行し、2文ごとに段落を分ける
