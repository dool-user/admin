# 営業文面の A/B テスト（10/12 社長の指示）

「何通かテストで送り、AB 検証で良いものに変えていく」。1回に比べるのは2案だけ、変えるのは1か所だけ（どこが効いたか分かるように）。

## 決まり
1. 送る前に、このファイルにテストを登録する（比べる案・見る数字・最低件数・判定の決まり）。送ってから決めない
2. 割り当ては `python tools/ab_test.py assign`（区分ごとに A・B を交互）。AP・SV は案を選ばない
3. 判定は `python tools/ab_test.py report`。**両方の案が最低件数を送るまでは「途中」**。少ない数で決めない
4. 勝った案を `templates.md` の共通の型に入れ、負けた案を外し、次のテストを1つ登録する
5. 送る相手・送る時間・リストの選び方は、テストの途中で変えない（変えたら、そこでテストを区切って記録する）
