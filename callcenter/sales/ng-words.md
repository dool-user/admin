# ng-words.md（使わない言葉）

`mistakes.md` の中から、言い回しの直しだけをここに移す。

| 使わない | 代わりに |
|---|---|
| 絶対儲かります／必ず来店が増えます | 「Googleマップからの来店を増やす方法の1つとしてご案内しています」 |
| 今だけ／本日中に | （期限がある場合は事実だけを伝える） |
| 皆さんやってます | 「近くの◯◯さんも始められています」（事実のときだけ） |
| 競合店の悪口 | 使わない |
| 「1位にします」「上位表示を保証」 | 順位は Google が決める。保証はできない |
| 「口コミを増やします」「★5を集めます」（見返り・代行を匂わせるもの） | Google のポリシー違反の手法を連想させる。使わない |
| 「Google公認」「Google提携」 | 事実でなければ使わない |
| 「至急ご返信ください」「ご返信がない場合は…」 | 使わない（返信は相手の自由） |
| 「突然のご連絡失礼いたします」を2回以上 | 1回まで |
| （医療あて）「患者さんが増えます」「口コミで集患」 | 「Googleマップでの医院の情報を正確に保つ方法のご紹介です」 |
| （士業あて）「地域No.1に」 | 使わない（比較・誇大の表現） |
