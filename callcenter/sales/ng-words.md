# ng-words.md（使わない言葉）

`mistakes.md` の中から、言い回しの直しだけをここに移す。

| 使わない | 代わりに |
|---|---|
| 絶対儲かります／必ず売上が上がります | 「売上を増やす方法の1つとしてご案内しています」 |
| 今だけ／本日中に | （期限がある場合は事実だけを伝える） |
| 皆さんやってます | 「近くの◯◯さんも始められています」（事実のときだけ） |
| 競合店の悪口 | 使わない |
| 「至急ご返信ください」「ご返信がない場合は…」 | 使わない（返信は相手の自由） |
| 「突然のご連絡失礼いたします」を2回以上 | 1回まで |
