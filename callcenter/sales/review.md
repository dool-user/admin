# review.md（出す前の点検）

文面・返信・アポを出す前に全部確かめる。1つでも ✗ なら直してから出す。

- [ ] 送り先のフォーム・プロフィールに「営業お断り」「セールスご遠慮」などの表記がない
- [ ] 同じ店に、この30日で送っていない（`outbox.csv` で店名・URLを確認）
- [ ] 店名・エリアが正しい。店について書いたことは実際に確かめたこと
- [ ] 名乗り（会社名・名前）と、連絡先・署名がある
- [ ] 連絡が不要な場合の伝え方が書いてある
- [ ] `ng-words.md` の言葉を使っていない。数字は `knowledge.md` にある値だけ
- [ ] 1通目で申込を迫っていない。目的は「15分の説明（デモ）の日程」だけ
- [ ] 順位の保証、見返り付きの口コミ集めを思わせる表現がない
- [ ] 検索順位・口コミ数などの店の数字は、実際に確かめた値だけ
- [ ] 送る手段は HP の問い合わせフォーム（Instagram DM は使わない・10/7〜）
- [ ] 宛名・敬語が丁寧版（`templates.md`）になっている
- [ ] 医療（クリニック・歯科）あてに、口コミ・評価・患者数の話を書いていない
- [ ] 士業・住まいあてに、相手の業務の広告（料金比較・物件・工事）の話を書いていない
- [ ] アポは決裁者（店長・オーナー・院長・代表）本人の返信で、日時・店名・連絡先がそろっている

## 嫌われない営業の点検（案・note 事業部 タロより 2026-09-29）
店舗オーナーが「しつこい MEO 業者」と感じる文面にしないための追加項目。SV が採用を判断する。
- [ ] 1通目で料金・契約の話をしていない
- [ ] 「無料診断」「今だけ」など、業者の決まり文句を使っていない
- [ ] 断られた店、返信のない店に、1週間以内に同じ内容を再送していない（再送は1回まで）
- [ ] 「Google から連絡が来た」「このままだと表示されなくなる」など、不安をあおる書き方をしていない
